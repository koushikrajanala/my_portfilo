# Koushik Rajanala — Developer Portfolio

A modern, responsive student developer portfolio built with semantic HTML5, CSS3, and vanilla JavaScript.

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive dark/glassmorphism design
- `script.js` — mobile navigation, reveal animations, and current year

## Customize
Search `index.html` for `[ADD` and replace the placeholders with your real:
- Skills and technologies
- Projects and project links
- Education details
- Achievements and certifications
- Professional email
- GitHub and LinkedIn links

The portfolio intentionally does not invent personal achievements, grades, projects, or certifications.

## Run locally
Open `index.html` in a browser, or serve the folder with any simple local web server.
